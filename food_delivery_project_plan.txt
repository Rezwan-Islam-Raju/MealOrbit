# 🍔 MealOrbit — Food Delivery Backend API

## Current Development Plan

---

# 🎯 Project Goal

MealOrbit is a production-style **Food Delivery Backend API** built with FastAPI.

The project focuses on real-world backend development including authentication, role-based authorization, async database operations, background processing, caching, real-time communication, payment integration, AI integration, testing, Docker, and deployment.

# 🚧 24. Production AI Deployment

Gemma 3 1B works locally but is not currently deployed with the main Render API.

Reason:

```text
Gemma 3 1B
+
PyTorch
+
Transformers
```

requires more memory than the current API hosting environment can reliably provide.

Planned production architecture:

```text
Main MealOrbit API
        ↓
Separate AI API
        ↓
Gemma 3 1B
```

The AI service will be deployed separately on a higher-memory environment.
