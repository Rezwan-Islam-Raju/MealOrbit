# 🍔 Food Delivery Backend API

## 🎯 Project Goal

একটি production-style **Food Delivery Backend API** তৈরি করা হবে যেখানে Customer, Restaurant, Food, Cart, Order, Payment, Rider, Review, Notification এবং AI Assistant থাকবে।

Project-এর মূল লক্ষ্য হবে শুধু CRUD না করে **real-world backend architecture** practice করা।

# 9. Order Item

একটি order-এর ভিতরে multiple food থাকতে পারবে।

Example:

```text
Order #1001

Burger × 2
Pizza × 1
Coke × 2
```

Order Item fields:

```text
id
order_id
food_id
quantity
price
subtotal
```

Important:

Order তৈরি হওয়ার সময় food-এর বর্তমান price `OrderItem.price`-এ save করতে হবে।

কারণ পরে food-এর price পরিবর্তন হলেও পুরোনো order-এর price পরিবর্তন হওয়া উচিত নয়।

# 19. AI Food Assistant 🤖

Example:

```text
User:

আমার budget 500 টাকা।
Chicken খাবার চাই।
Spicy খাবার চাই।
```

AI:

```text
আপনার জন্য:

1. Chicken Burger - 250 BDT
2. Spicy Chicken Pizza - 400 BDT
3. Chicken Wings - 300 BDT
```

AI database-এর available food data ব্যবহার করে recommendation দেবে।
